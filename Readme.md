## ✨ About This Repository

This repository documents my **ReactJS learning journey** through a sequence of focused projects.

The course starts with React fundamentals and gradually moves into component design, props, custom hooks, UI libraries, and global state management with Zustand.

> 💡 **Learn the concept → build the feature → understand the code → repeat.**

## 🚀 Project Highlights

### 01 — Start

A minimal React project using Vite, introducing the basic project structure and dependencies.

**Key technologies:** React, React DOM, Vite

### 02 — Design Work

Focused on UI/UX and styling, including Tailwind CSS and icon libraries.

**Key technologies:** Tailwind CSS, Huge Icons, class-variance-authority

### 03 — ShadCn

Explores reusable UI components using shadcn/ui and Radix UI.

**Key technologies:** shadcn/ui, Radix UI, Lucide React, Tailwind CSS

### 04 — Counter Project

A simple counter project focused on component-level state management with `useState`.

**Key technologies:** React, React DOM

### 05 — Queue Management

A project focused on lists, state, and dynamic user interactions.

**Key technologies:** React, React Icons

### 06 — Prop Guide

A practical project for understanding props and communication between React components.

**Key technologies:** React, Tailwind CSS

### 07 — Custom Hook

Demonstrates how custom hooks can extract and reuse stateful logic.

**Key technologies:** React, React Icons, Custom Hooks

### 08 — State Management — Zustand

Explores global state management using Zustand, including stores and reusable state across components.

**Key technologies:** React, Zustand

## 🛠️ Getting Started

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm or yarn
- Git

### Clone the Repository

```bash
git clone https://github.com/manishmotirale/ReactJS_Course.git
cd ReactJS_Course
```

### Choose a Project

For example:

```bash
cd 01_Start
```

### Install Dependencies

```bash
npm install
```

### Start Development

```bash
npm run dev
```

Vite will provide a local development URL, usually:

```text
http://localhost:5173
```
